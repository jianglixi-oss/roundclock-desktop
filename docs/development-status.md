# v1.0 验证范围与已知限制

v1.0 为首个正式发布版本，发布日期2026-10-28。以下说明验证范围与仍需扩大测试的场景。

已在一台指定 ESP32-S3 圆屏上验证：显示、触摸、菜单、模拟时钟、Wi-Fi 扫描和 NTP；Hermes 语音文字对话；Codex 用量、工作状态和完成提示；股票清单行情。
时钟 Codex 工作状态常驻修复已通过超过14秒的实机帧缓冲检查。
股票搜索代码、中文、拼音首字母和全拼已验证；并发增删及旧列表覆盖问题有独立 HTTP 契约检查。

尚需更多实测：超过5只股票的物理拖动、断线/长时间运行、多任务状态、不同批次面板和语音音量/打断体验。
本次源码整理把实际网络地址和令牌改成配置示例，字库由本地脚本生成；不应把个人实机镜像当作可分发固件。

第三方公开行情端点、在线 TTS 和 Codex 本地事件格式都可能变化。没有保证固定响应延迟。

设置/横向菜单：用户已确认滑动、放大和设置开关正常。夜间跨午夜及日间窗口边界、50% PWM占空比读回检查通过，检查后恢复原占空比。
用户选择的夜间模式和应用开关已在再次刷写后的启动中读回，未清除NVS或覆盖用户选择。
菜单基准的旧版测量为5.61fps，单帧159.88ms（绘制36.85ms、传输/等待122.57ms）；优化后的对照测量见menu-performance.json。
最终优化版基准25.53fps，单帧29.45ms（绘制6.26ms、传输/等待22.85ms）。设置页随后按误触反馈改为分层大目标、抬手确认。
性能基准是在稳定菜单上连续刷新24帧，不能当作所有界面和手势过程的固定帧率；动画目标约30fps、220ms吸附。
维护命令：PREFS查询设置，SETTINGSTEST检查时间边界/PWM，BENCH在应用菜单测刷新耗时。
