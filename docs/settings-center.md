# 统一设置中心（v1.0）

NAS 地址：http://YOUR_NAS_IP:8767/settings。配置页面无需登录、验证码或股票设置码。

- 网络：查看圆屏连接状态、SSID、IP、信号；首次配网仍连接设备热点访问192.168.4.1。
- 股票：嵌入自选管理，支持代码、名称和拼音查询，保留原列表。
- Hermes：网关地址、API密钥、对话模型、TTS引擎、音色、语速、音高；连接测试。密钥不返回页面；留空保留，切换另一主机时清空旧密钥。
- Codex：同步在线状态、用量刷新30—600秒、状态同步2—10秒；完成提醒可选语音、短音或关闭。

配置写入语音桥自身JSON文件，不修改原Hermes环境文件。电脑同步程序需使用新版monitor.py以读取间隔设置；设备需新版固件以应用声音选项及回报网络状态。机器接口继续使用原Bearer鉴权。

验证：真实手机尺寸页面导航和保存；原自选列表读取；Hermes连接测试；9项隔离接口检查；固件编译、刷入校验、联网时钟状态与网络上报。
