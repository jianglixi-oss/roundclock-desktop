# 圆屏 Codex 同步程序

当前用户登录后，由启动文件夹的 `RoundClock Codex Monitor.lnk` 隐藏运行 monitor.py。
已经安装并启动；无需手动打开终端。Python 及 Codex 桌面端需要继续保留在这台电脑上。
当前目录不要移动；移动后重新运行 install-startup.ps1 更新快捷方式。

用量通过官方 Codex app-server 的 account/rateLimits/read 只读接口获取，每 120 秒刷新。
显示账户共享的额度已用百分比，不是本次聊天的 token 计数；未知值显示未知，不显示为 0。
状态在本机只读解析 `.codex/state_5.sqlite` 的 rollout 路径和会话生命周期事件，每约 3 秒同步到 NAS。
工作开始、用户输入请求、完成和中断事件映射为小机器人状态。等待输入基于本地工具事件识别；不同版本的事件格式变化可能需要适配。
不启动推理对话，不修改现有 Codex 任务、账户或额度。

NAS 只收到：状态、活动任务数、两个额度窗口的已用百分比与重置时间、同步时间。
账户凭据、账户 ID、聊天正文、工具命令、文件内容均不会上传。
NAS 入口使用专用写入令牌，只能写入上述快照；设备令牌只读取快照。
config.private.json 为本机配置，包含中继写入令牌，不打入分发压缩包。
NAS 收不到心跳 25 秒后，设备显示“电脑离线”；用量超过 10 分钟未刷新则显示待更新。

圆屏主菜单右侧为 Codex；默认显示 5 小时及每周用量、北京时间重置时间和状态小机器人。
底部返回菜单。工作中和等待回复时，时钟页及菜单的状态持续显示；完成和异常提示保留10秒。点击时钟页提示可进入 Codex。
完成时播放女声“任务已完成”，同次完成去重；Hermes 打开时延后到退出后播放，语音失败则回退提示音。

停止自动同步：删除当前用户启动文件夹中的 RoundClock Codex Monitor.lnk，并结束对应 monitor.py 的 pythonw 进程。
恢复自动同步：在此目录执行 install-startup.ps1。health.json 是运行状态记录，monitor.lock 防止重复启动。

验证：官方接口返回的用量已与桌面工具核对，PC→NAS→设备成功；用户确认两条用量、重置时间和工作状态正常显示。
本地中继契约检查覆盖鉴权隔离、未知用量、非法状态和心跳超时。

接口参考：https://learn.chatgpt.com/docs/app-server
